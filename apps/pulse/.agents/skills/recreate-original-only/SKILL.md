# Original shoots only

Inspired by format, never ripped footage, audio, or captions.

A paste pack includes:

- hook and on-screen text
- caption line 1, body, hashtags, comment prompt, soft CTA
- CapCut scene outline with about 3–5 second scenes
- Descript chapter titles and scratch VO
- camera notes for Pocket 4, Osmo 360, and Mic Mini

Do not build Descript, CapCut, or Opus editor UI.
