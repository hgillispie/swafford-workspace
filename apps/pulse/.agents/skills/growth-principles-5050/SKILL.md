# Growth principles

- Split the week about 50/50 between search and trend (hybrid counts with trend).
- Metadata stack on every card: on-screen keyword, spoken keyword in the first
  second, caption line 1, keyword hashtags, local geo tags.
- Edit cadence: scene changes about 3–5 seconds.
- Post in the stored America/New_York windows. Reply in the first hour.
- Follower count ÷ total likes should be about 15% or higher. Say so when a
  stored snapshot is under that. Do not invent analytics Pulse does not have.
